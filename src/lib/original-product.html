FAQ

GeneralCompatibility

1. What kind of doors are eufy FamiLock S3 Max compatible with?

Compatible with most standard doors, door thickness:35-55 mm. Do not recommend to install on the door that has a storm door in front, which might block the view. If your latch recess is round, contact eufy Support to get a round drive-in faceplate.

2. What should be noted when using the palm vein unlocking function?

You can store palm vein information for 50 family members. The palm vein can only be used to unlock, not to lock.

3. What is the power supply method of this door lock? What happens if the battery runs out?

Our door lock uses a dual power supply with lithium and standard batteries. When the lithium battery is low, standard batteries provide emergency power, allowing PIN code access to lock/unlock, while other functions are unavailable.

1. Which eufy devices and systems are eufy FamiLock S3 Max compatible with?

It supports connection with Homebase™ 3 and is expected to be compatible with HB2 in Q2 of 2025. Without Homebase™, it links to other eufy cameras, letting you remotely lock/unlock via live view on any device.

2. Does eufy FamiLock S3 Max support external integration with other smart home platforms?

Camera streams are not supported via Matter due to current limitations. For full features and the best experience, please use the eufy App. Matter is now compatible with HomeBase™3 for simultaneous use. This video lock is not compatible with HomeBase™ 2.
